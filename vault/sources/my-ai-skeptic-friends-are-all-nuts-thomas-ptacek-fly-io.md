# My AI Skeptic Friends Are All Nuts (Thomas Ptacek, Fly.io)

## Takeaways
- Scope is software development only; the author explicitly defers to sceptics about art, music and writing.
- Claim: people coding with LLMs now use agents that read the tree, run tools, compile, test and iterate; the agent code is simple systems code "wired to ground truth", so sceptics who paste ChatGPT output into an editor are arguing about a different thing.
- Hallucination: if a model invents a function signature the agent sees the compile or lint error and retries; the author calls hallucination "more or less" solved for coding agents.
- Responsibility: "read the code" for anything people depend on; the author edits LLM output into his own style and does not merge unedited output. This is a position against unreviewed code.
- Other arguments: LLMs raise the quality floor, handle schlep, work better in languages with good tooling; a lengthy dismissal of intellectual-property objections; honest uncertainty about jobs.
- Date and tone: June 2025 (models named are Gemini 2.5, o3, 4o), profane and provocative. It is one experienced practitioner's experience, with no data.
