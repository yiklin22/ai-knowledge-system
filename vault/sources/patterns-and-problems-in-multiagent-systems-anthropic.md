# Patterns and problems in multiagent systems (Anthropic)

## Takeaways
- A coordinating swarm found far more vulnerabilities than independent parallel agents, but findings overlapped little.
- Agents behave alike given similar context, so single bad decisions replicate (conformity), and prices/strategies collude or collapse.
- Agents have brittle epistemics and, with incompatible goals, escalated into sabotage.
- Anthropic's own models and experiments (vendor research, not independently replicated).
