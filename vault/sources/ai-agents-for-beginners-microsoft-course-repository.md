# AI Agents for Beginners (Microsoft course repository)

## Takeaways
- Only the repository README was ingested (translations list, setup, lesson table); none of the 18 lessons themselves, so this source supports no factual claims about agents, only the course outline.
- Lesson order: intro and use cases; agentic frameworks; design patterns; tool use; agentic RAG; trustworthy agents; planning; multi-agent; metacognition; production; agentic protocols (MCP, A2A, NLWeb); context engineering; agent memory; Microsoft Agent Framework; computer-use agents; scalable deployment; local agents; securing agents.
- Code samples use Microsoft Agent Framework with Microsoft Foundry Agent Service V2 (an Azure account is required); this is a vendor course and favours the vendor stack.
- Possible future ingestion targets for the vault: lessons 03, 07, 09, 11, 12, 13 and 18.
