# Best practices for Claude Code (Claude Code Docs)

## Takeaways
- Instructions are either non-deterministic (prompt, CLAUDE.md, skills) or deterministic (hooks, deny rules, settings).
- Give Claude a pass/fail check; keep CLAUDE.md short; know what subagents cost.
- Vendor documentation for one product; recommendations change as models improve.

Headings: Deterministic and non-deterministic instructions · Tell Claude what it can't see · Keep CLAUDE.md short · Give Claude a check to run · Enforce the rules that can't have exceptions · Know what subagents cost · Keep cost and context down · What you can stop doing.
