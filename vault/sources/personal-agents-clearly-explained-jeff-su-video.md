# Personal Agents, Clearly Explained (Jeff Su video)

## Takeaways
- Three tiers: chatbots (one-off tasks), DIY agents (ChatGPT Work, Codex, Claude Code, Gemini Spark: they read and update plain-text memory and rule files), and personal agents (Meta's Muse, ChatGPT dots, Grok bot: ready-made and proactive).
- The presenter's own setup is a home folder of 100+ text files ("Jeff OS") that the agent writes and maintains; he says Muse's system files look "remarkably similar", including memory.md and agent.md.
- Proactive means the agent watches for events and messages you first, which the presenter says a once-a-day scheduled task would miss; he says they run on dedicated cloud computers.
- Reasons to still prefer DIY: personal agents are newer and less capable, impose one standard structure, and cause ecosystem lock-in. Privacy is framed as a personal preference; local open-source agents (OpenClaw, Hermes) give privacy but are harder to set up and cannot run the strongest models.
- The channel sells courses and a "second brain" template shown in the video; product claims are the presenter's impressions.
