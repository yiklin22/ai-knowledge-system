# Are LLM economics sustainable as agents and reasoning raise token use?

## Why I'm asking
- Zitron says costs rise and nobody is profitable; Willison says spend soared then companies capped it. This affects which agent patterns (many subagents, high effort) are practical for personal use.

## What would answer it
- Audited financials or filings from model providers, with gross margin by product.
- Price per token over time against tokens per task for comparable work.
- Measured cost of the patterns already in the vault (subagents, high-effort modes), not creator estimates.
