What happened

Why. Generating token t+1 needs the query of the newest position, and the keys and values of every position so far. In a decoder with a causal mask, the keys and values of old positions depend only on earlier tokens, so they never change. A cache stores them (per layer, per KV head) and each step only computes K, V (and the MLP) for the one new token, then appends.

What does not go away. Each step still scores the new query against all t cached keys, so attention cost per step still grows with t (the q·k row above drops from cubic to quadratic, not to linear).

The price. Memory: 2 × L × Hkv × dhead × bytes × tokens (the 2 is K and V). It grows linearly with sequence length, which is why long contexts and many concurrent users are often limited by memory, and why designs with fewer KV heads (grouped-query or multi-query attention) shrink it.

Simplifications. Toy cost model: every position costs one unit regardless of model size; prompt length is 0; batching, prefill chunking and paged caches are ignored. Memory figures use the formula exactly, but L and Hkv are free sliders, not a specific model. Without a cache the K/V tensors exist transiently inside each step; “extra memory held” counts only what is kept between steps.
