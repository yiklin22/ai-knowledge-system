# Learn 99% of Claude Code in One Video (Tech With Tim)

## Takeaways
- The video opens with "This video is sponsored by Anthropic", so treat product advice as sponsored. Recorded on 9 Oct 2026 per the presenter; model names, plans and defaults are volatile.
- Model advice: leave the default (Opus 5.5) on higher plans, use Sonnet 5.5 or Haiku to stretch usage, and rarely switch to Fable. Effort: medium as everyday default; the presenter says high roughly doubles usage and time versus medium, and higher levels can run for hours (personal experience, not measured data in the video).
- Permission modes: auto (default), manual, accept edits, plan, bypass; the presenter recommends auto, with plan mode for new projects and having the model interview you first.
- Customisation layers explained: CLAUDE.md (read every session), memory files, settings.json permissions, skills (reusable markdown instructions), subagents, MCP servers, hooks (fired by the harness on events), plugins (bundles) and mods (harness-level customisations shipped in plugins).
- Context management: /context, /clear, /compact, /rewind; larger context means more mistakes and more cost. Parallel sessions can use worktrees, which avoid overwriting but not merge conflicts.
- The demo and explanations are the presenter's own use; several features were explained by asking Claude itself rather than by documentation.
