# What is agentic engineering? (Simon Willison)

## Takeaways
- Agent = tools run in a loop to achieve a goal. Coding agents add code execution.
- Agentic engineering is the practice of developing software with coding agents; vibe coding is a narrower term for unreviewed prototype-quality code.
- Humans still decide what to build, specify problems, and verify results.
